# User guide - current recovery build

BrahmaGPT is an internal demonstration workspace, not an official government deployment. Use only fictional data. Open http://localhost:3000 after following WINDOWS_SETUP.md. Local employee entry can bypass the login form when explicitly enabled. /login remains available for separate seeded reviewer/admin accounts; public registration is unavailable.

## Profile and Customize

The avatar-only control at bottom left opens nine Profile sections. My Profile has overview/employment/contact/roles/private-file tabs. Edit permitted contact fields, upload a monochrome avatar or private PDF, and save. Official identity/designation fields are not verified and cannot be self-assigned. Setup & Department Access creates a justified request with scope/role/duration; an administrator must decide before the membership appears in the top selector. Switching changes the active scope, not document permissions.

Connected Apps lists providers and records connection requests; no external account is configured. AI & Models exposes only the deterministic excerpt capability and actual tracked action counts. Security allows password verification/change and per-session revocation; MFA/passkeys/recovery are not implemented. Notifications persists in-app preferences; quiet hours/digests are not operational. Activity filters/exports only your audit history. Preferences saves/applies appearance, text size, date/time, sidebar and motion options; untranslated language preferences and workflow defaults are clearly labelled. Help searches guides and creates persistent support tickets.

Customize has six distinct tabs. Add available tools to Favourites, reorder with Move up/down, launch a tool to record actual recent use, clear optional recents, dismiss recommendations, filter the catalogue and request a tool. Quick-action shortcuts use the same permission-checked favourites. Connected Tools stays empty until a real provider exists. Counts come from persisted data.

## Projects, tasks and department work

Create a project with purpose, invite already-authorised colleagues, assign project roles, create linked tasks, upload files, post discussion and schedule internal meetings. Meeting minutes persist; no external meeting URL is fabricated. Project membership never overrides source-file restrictions. Owner settings permit archival. Advanced milestones, ownership transfer and reporting remain incomplete.

My Tasks unifies personal, project and case tasks. Assign to an authorised colleague, choose priority/date, update status, add comments and follow source links. Calendar displays actual due dates. Recurrence/dependencies and background reminders are not implemented; completing a task never approves a file.

Pension and Public Grievances have distinct registration forms and illustrative state transitions. Pension verification checks and deficiencies must be complete before review. A separate authorised reviewer controls forwarding. Grievances require a saved proposed response before review; a separate reviewer resolves them. Assignment, attachments, canonical follow-ups, correspondence and history persist. No statutory deadline, pension sanction or official dispatch is implied.

## Documents and human review

Upload a genuine PDF/DOCX/UTF-8 TXT reference. Originals are immutable; extracted text keeps version/hash and page/paragraph metadata. Scans without readable text are rejected because OCR is not configured. Select at least two sources and enter a drafting brief. DEMO drafting selects keyword-relevant explicit excerpts; it does not verify law, generate signatures or invent absent facts.

Inspect each citation, exact original and marked passage. Recommendations are suggestions, separate from sourced facts and unknowns. Accepting one creates a new version; dismissing persists. Edit/save immutable revisions, compare versions and restore an earlier version as a new review copy. Unsupported factual lines block grounded submission. Submit a saved version to a separate authorised reviewer, who may return/reject/approve with a comment. Source access is rechecked and a later version cannot inherit approval. The queue has links to the exact submitted version.

Exports are review copies in DOCX/PDF/PPTX/XLSX with evidence metadata. Final official issuance, verified signatures, full template administration and export visual QA remain unfinished.

## Outreach and administration

Outreach uses a SIMULATED provider only. Create a fictional campaign/script, record human language review, add aliases and consent, obtain separate human review, then explicitly confirm simulation. Receipts persist; nonconsented/opted-out contacts are skipped. No real messages/calls are sent. Advanced scheduling/retry/reporting is incomplete.

Administrators use /admin through the avatar menu. Review department requests, answer support tickets or create a version-1 departmental form tool. Saving a configuration does not activate it; explicit activation with a comment is required. Authorised staff then see the form in Department Work/Customize and can save entries/advance configured states. Full identity/policy/retention/secret management is not implemented.

See ACCEPTANCE_MATRIX.md and KNOWN_LIMITATIONS.md for failures and verification scope. Do not treat a working demonstration path as full-product or production acceptance.

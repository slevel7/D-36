# User guide

Use the synthetic employee credentials described in README. Projects, My Tasks, Pension and Public Grievances currently support basic scoped record creation and listing. Documents is the primary working vertical slice: enter reference text, select two references, compile a DEMO office note, inspect precise evidence, save immutable manual revisions and export review copies. No factual/legal verification is implied.

A separate designated reviewer uses Approval queue. Sign out before switching demonstration users. A saved manual revision is intentionally not approved and currently cannot be regrounded through the editor. Profile shows identity and security limitations; Preferences stores theme in the backend. The remaining nine profile/six Customize full workflows are not complete. Unconfigured integrations cannot connect or send. See WALKTHROUGH for exact reproducible steps and FEATURE_MATRIX for feature status.

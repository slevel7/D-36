# Known limitations

The complete master specification is not implemented. See FEATURE_MATRIX.md for exact scope. Record CRUD is a foundation, not a complete pension, grievance, project or task workflow. No pension sanction, official forwarding, signature, external sending or legal validation exists.

The original lotus asset is missing. No Docker executable is installed. No production credentials are configured. PostgreSQL, worker/object storage integration, migrations, external connectors, browser automation and visual regression remain unverified or unimplemented. User profile/customize sections honestly disclose absent functionality. Plain text source entry supports paragraph anchors only, without page numbers. New manual revisions intentionally lack citations and cannot be submitted; regrounding and structured claim validation are not yet implemented. Approved versions remain immutable but workflow configuration and final issue states are absent.
